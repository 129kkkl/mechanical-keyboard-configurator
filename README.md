# 星轨键盘工作室 STELLARAIL Studio · 机械键盘配置器（v3）

原创多配列机械键盘的 3D 产品配置器。**双击 `index.html` 即可离线使用**：Three.js r160 已整体内联，不依赖 CDN、远程字体、在线图片或任何运行时服务。

## 目录结构

```
index.html          最终交付物（自包含单文件，由构建脚本生成，勿直接手改）
build.mjs           构建脚本：node build.mjs → 重新生成 index.html（无第三方依赖）
src/
  template.html     页面模板
  style.css         样式
  data.js           数据模型：六套配列、四个外观系列、五外壳色、六键帽主题、
                    三轴体、两套键帽轮廓、毫米制结构参数（STRUCT）
  app.js            应用主体：参数化键帽/装配工厂/相机/交互/存储/UI
  vendor/three.min.js  Three.js r160 官方构建（内联用）
tools/
  validate-layouts.mjs 布局自动验证（node tools/validate-layouts.mjs）
备份_v1_20260929/   v1 原始单文件版
备份_v2_20260929/   v2 多配列版（含当时 src/ 与构建脚本）
docs/
  验收报告.md        v2 验收报告
  v3验收报告.md      v3 拟真精修验收报告
  screenshots/       验收截图（00–13 为 v2，v3_ 前缀为本轮）
```

## 常用命令

```bash
node build.mjs                    # 构建 index.html
node tools/validate-layouts.mjs   # 布局数据校验（含旧 16u 越界回归测试）
```

## 功能概览

- **六套配列**：K60（61 键）/ K65（68）/ K75（82）/ K80 TKL（87）/ K96（101）/ K100（104），键数与尺寸（外壳/键位区，毫米）全部由数据计算。
- **四个外观系列**：极简铝合金 / 复古工作站（厚边框双色、指示灯、型号铭牌）/ 半透明外壳（高质量档为物理透射，低功耗档为半透明近似）/ 旋钮工作站（K75 Pro 专用，滚花金属旋钮可拖动调节试轴音量）。
- **两套原创键帽轮廓**：流线·低矮雕刻（逐行高度差与倾角）/ 复古·高球面凹顶（统一高度深凹顶）。参数化 loft 网格：收分侧壁、肩部过渡、浅凹顶面、内裙与轴心座。
- **真实装配五层**：底壳（底板+环形侧壁+承托台阶+脚垫支撑倾角+USB-C 开口）→ PCB（丝印+热插拔轴座）→ 定位板（按布局开轴孔与稳定器槽）→ 轴体·稳定器（底座/上盖/十字轴心，钢丝稳定器含竖向 2u）→ 键帽。按压时键帽、轴心、稳定器座联动，行程 2.0mm（视觉演示值），最低点不穿板。
- **材质与灯光**：程序生成棚拍环境（PMREM 预过滤反射）、ACES 色调映射、中性棚拍/暖色桌面/深色轮廓三种灯光场景、质量高低两档（细分/阴影/透射成本分级）。
- **展示交互**：五视角预设（包围盒取景）、点击部件聚焦（名称/材质说明/返回全景）、取帽模式（点击取下/放回）、层隔离、专注展示、自动旋转开关。
- **体验模式**：A–Z/空格等真实按键下压回弹 + 合成试音（三类轴体，音量/静音独立）；输入框聚焦不劫持；触屏点按；最近按键与计数可清除。
- **方案管理**：多方案命名保存/载入/改名/复制/删除、版本化 JSON 导入导出、两方案对比（实时快照+差异表）、PNG 配置卡导出（当前视角）。
- **可靠性**：版本化存档 + 旧版 v1 迁移（不删旧数据）、损坏回退提示、保存失败真实报错、WebGL 降级（二维键位图与配置仍可用）、遵循减少动态效果偏好。

## 移动端

窄屏（≤1100px）隐藏左侧产品区，改用顶部「☰ 选型」抽屉选择配列与系列；页面改为上下堆叠，模型先行、配置随后。

## URL 参数

- `?perf=1` — 显示 FPS / DrawCalls / 资源计数 HUD
- `?autoswitch=N` — 自动循环切换 N 次配列×系列（压测用）

## 参数与数据来源说明

- 1u = 19.05mm 仅为本项目换算；`STRUCT`（data.js）中壁厚/板厚/脚垫/行程等为**原创设计值**，非真实厂商规范。
- 两套键帽轮廓为**原创设计**，不对应特定商品 profile。
- 价格为固定规则计算的**演示估价**；试音为 WebAudio 合成演示，非轴体实录。
- PCB 丝印与轴座为**结构示意**，不代表可制造电路。
