# v3 键帽破面修复

日期：2026-09-29。用户反馈：本轮修改使键盘外观、模型或材质变差。

## 已确认原因

历史截图 `v3_00_首屏_K65.png` 与侧视截图中，键帽侧壁缺失、轴体外露。当前源码对应三个明确问题：

1. 外侧壁三角形绕序反向，单面材质从外侧观察时会剔除这些面。
2. 圆角肩部与矩形顶面是互不连接的网格，且高度不同，留下缝隙。
3. 内裙与外裙未连接，内裙绕序也不符合朝向内腔的要求。

原 `v3验收报告.md` 的首屏“通过”不能证明模型正确；其截图本身已经显示退化。保留原报告作为历史记录，以本记录说明此次修复及验证边界。

## 修改

- 修正外侧壁与内壁绕序，继续使用单面材质，没有以 DoubleSide 掩盖破面。
- 用与肩部共享顶点的圆角环逐层构建凹顶，补齐底缘与内腔顶的连接；保留底部内腔。
- 顶面和肩部使用一致的凹面/倾角计算，增加肩部过渡及采样，避免原先悬空的直角顶片。
- F/J 定位凸点按实际凹面高度放置，减少原先固定高度导致的悬浮。
- 保留配列、材质、方案和其他 v3 功能，本次没有整体回退或继续扩展功能。

修复前完整快照：`备份_v3修复前_20260929_225142/`。更早的 v2 备份也保留。
