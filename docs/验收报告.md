# 验收报告 · 星轨键盘工作室（v2 升级）

日期：2026-09-29。环境：Windows 11，Node v22.23.2，Kimi Code 内置 Chromium 浏览器（1280×720 CSS 视口）。

## 已完成的修复（对应审计 P0–P2）

- **P0 布局越界**：旧 64 键底行 16u 超出 15u 外壳的问题，通过把 65% 重新定义为 16u 宽（含右侧导航列 Del/PgUp/PgDn/Home + 倒 T 方向键）根治；外壳宽度一律由布局占用范围 + 系列边框推导，不再硬编码。回归测试保留：`tools/validate-layouts.mjs` 内置旧版 16u/15u 数据，验证探测器必然检出越界。
- **保存可靠性**：`persist()` 只在 `setItem` 成功时提示已保存；失败（如配额不足）显示红色错误条且内存态可继续操作；摘要中的保存状态反映本次真实结果。
- **输入劫持**：体验模式仅在非输入控件聚焦时响应；Ctrl/Meta/Alt 组合键直接放行；仅对 Space/方向键阻止滚动类默认行为；Tab/Enter 焦点导航不受影响。长按 `e.repeat` 不重复发声；`keyup` 释放、`blur`/`visibilitychange` 全部释放。
- **指针中断**：补 `pointercancel` / `lostpointercapture` 清理；双指捏合缩放；旋转与点按以位移阈值区分；旋钮拖拽与旋转手势互斥。
- **动画时间驱动**：相机、拆解、按键弹簧全部改为 deltaTime 驱动，`dt` 上限 50ms，静止不渲染，页面隐藏时暂停，遵循 `prefers-reduced-motion`。
- **可访问性**：开关为原生 checkbox（透明覆盖而非 `display:none`，可聚焦、有焦点环）；色卡/卡片为 `<button aria-pressed>`；视角按钮、拆解按钮均有 `aria-pressed`；toast 使用 `aria-live`。
- **WebGL 降级**：创建失败或 `webglcontextlost` 时显示说明卡与重载入口，配置界面与二维键位图仍可用。（验收中发现并修复了降级面板因 CSS `display:grid` 覆盖 `hidden` 属性而常驻遮挡的缺陷。）
- **数据同源**：布局/系列/颜色/主题/轴体全部集中在 `src/data.js`；键数、尺寸（mm）、估价、摘要、二维图、缩略图均由数据计算，不再写死。

## 验收中发现并修复的缺陷

1. 兼容回退在完全不兼容时 `D.getLayout(null).name` 抛异常，系列切换整体失效 → 修复 `applyCompat` 回退路径。
2. 色卡/卡片点击处理器闭包捕获渲染时的方案对象，"存为方案"后未重渲染的控件会把修改写进旧方案 → 全部改为处理器内实时 `currentConfig()`。
3. 移动端 hint 溢出、拆解态窄屏取景偏紧 → hint 允许换行、取景边距 1.04→1.12。
4. 降级面板遮挡（上述 CSS 缺陷）。

## 已知限制 / 未覆盖

- **直接 `file://` 双击未做浏览器实测**：内置浏览器工具按安全策略拒绝 file:// URL，未绕过；离线性由结构保证（构建校验无任何 http 外链，Three.js 内联）。
- 按压回弹的瞬时画面无法截图取证（回弹约 0.3s，快于截图延迟）；其逻辑为 deltaTime 弹簧，键盘事件记录已实证。
- 旋钮拖动调音量、双指捏合在桌面浏览器工具下无法完整模拟（捏合为合成指针实现，代码路径已审）。
- FPS 数值未给出绝对性能结论：按需渲染策略下静止即停帧（HUD 显示 FPS 0 属预期），交互期帧率未用专业工具测量，不做"稳定 60FPS"式声明。
- 半透明壳体未使用真实折射（transmission），为透明材质 + 内部结构层次的概念示意。
