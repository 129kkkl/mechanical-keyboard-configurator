# 定位板错位与异常板片修复

日期：2026-09-29。修复前快照：`备份_定位板修复前_20260929_225926/`。

## 根因

1. `roundedRectPath` 将键位的 Z 直接写进 Shape 的 Y。`ExtrudeGeometry.rotateX(-Math.PI/2)` 会把该 Y 转成负 Z，导致孔位前后镜像，而键帽和实例化轴体仍在原位置。104 键实测有 91/104 个轴心中心被原定位板实体挡住。
2. 竖向 2u 长键的稳定器孔只改变中心位置，没有旋转孔形。原轴孔半深 0.26，稳定器孔中心距 0.4、半深 0.15，二者重叠 0.01u。不相交孔的三角化前提被破坏，会造成异常板面风险。

上一轮键帽检查没有覆盖这两个问题。本轮增加实际板件网格与装配检查，不再只检查二维布局。

## 修改

- 在二维孔轮廓入口统一执行 Z→负 Y 换算，使挤出旋转后的孔仍处于键盘局部 X/Z 坐标。
- 将定位板创建集中到 `createPlateGeometry`，孔数据集中到 `plateCutouts`。
- 按稳定器横/竖方向同步旋转槽形，调整为相互分离且能容纳当前稳定器座的孔尺寸。
- 对实际定位板网格命名，测试在连续换板后检查每个装配只有一片定位板、场景只保留当前键盘。保留正常的 PCB、外壳底板和承托框，它们不是重复定位板。

## 本轮验证

执行：

```text
node tools/validate-plates.mjs 备份_定位板修复前_20260929_225926/src/app.js
node tools/validate-keycaps.mjs
node tools/validate-layouts.mjs
node --check src/app.js
node build.mjs
```

定位板验证结果：7 种配列变体，18 种兼容外观组合，10800 次实际网格射线检查通过。

- 每个轴孔与稳定器孔检查中心及四个内部采样点，均能穿过板件。
- 孔之间无矩形范围重叠。
- 板面实体区采用错开边界的网格采样，每条射线必须恰好命中一次上表面及一次下表面，排查缺面及多余重叠面。104 键包含 1255 个实体区采样点。
- 执行生产代码的真实 `buildBoard`，验证键帽与轴心位置相同；在装配倾角及抬升变换后，轴心仍对准真实孔位。
- 18 次换板后逐次验证场景仅保留一个键盘，每个键盘仅一片定位板，最终释放后场景为空。
- 修复前 104 键作为回归夹具，成功检出 91 个被板面阻挡的轴心中心。
