# v3 验收报告 · 星轨键盘工作室（拟真精修）

日期：2026-09-29。基线：v2（`index.html` SHA-256 `85810a41…` 前缀，已备份至 `备份_v2_20260929/`）。
环境：Windows 11，Node v22.23.2，Kimi Code 内置 Chromium（桌面 1280×720 CSS 视口，移动 iPhone 14 Pro 393×852 模拟）。

## 本轮根本重做的部分

1. **键帽**：双层 BoxGeometry → 参数化 loft 网格（圆角矩形底缘 → 收分侧壁 → 肩部过渡 → 浅凹顶面网格），带内裙与轴心安装座；按 w/h/轮廓/行/质量档缓存。两套原创轮廓（流线·低矮雕刻 = 逐行高度/倾角/凹面变化；复古·高球面凹顶 = 统一高度深凹顶），F/J 定位凸点（流线款）。
2. **装配结构**：外壳改为「底板 + 环形侧壁（真实内腔）+ PCB/定位板承托台阶」；定位板按布局逐键开轴孔与稳定器槽（与轴体同源坐标）；PCB 带丝印与热插拔轴座；轴体为底座+上盖+十字轴心三件（轴心颜色随轴体类型）；钢丝稳定器为弯折管，覆盖横向长键与数字区竖向 2u；USB-C 为壳体后壁开口 + 金属舌片；打字倾角由前后脚垫高度差（1.5mm / 8mm）产生，落地由包围盒接触点求值，不再整盘悬浮。
3. **材质光照**：程序生成棚拍环境 → PMREM 环境反射；ACESFilmic 色调映射；半透明款高质量档使用 transmission/thickness/ior（低功耗档诚实降级为半透明近似并在说明中标注）；字符贴图声明 sRGB 色彩空间。
4. **资源所有权**：脚垫/轴体/稳定器等几何改为创建一次的共享缓存；每块板的私有几何/材质以 ownGeo/ownMat 标记并随换板释放；字符贴图为共享缓存，销毁材质时不再误释放贴图。

## 修复的装配/展示错误

- PCB 与内托、轴壳与无孔定位板的体积交叠 → 高度链由毫米参数推导（板面低于壳沿、键帽裙底压住壳沿），按压行程 2.0mm（视觉演示值），最低点不穿板。
- 字符为不受光照的悬浮平面 → 跟随凹面与行倾角的曲面贴片，MeshStandardMaterial 受光照。
- 铭牌固定 "STELLARAIL · 87" → 按当前型号与键数生成。
- 尺寸文案只报键位区 → 同时显示外壳尺寸（含边框）与键位区。
- 复位不能恢复自动旋转 → 独立开关控制；聚焦部件时自动暂停。
- ≤1100px 直接隐藏选型区 → 增加「☰ 选型」抽屉入口。

## 新增展示能力

点击部件聚焦（相机以命中点为目标平滑拉近 + 名称/材质说明卡 + 返回全景）；取帽模式（点击取下/放回，可见内部轴心座）；层隔离（五层逐层查看）；专注展示；三种灯光场景；质量高低档。

## 受限与已知不足（如实记录）

- **移动端点击未实测通过**：内置浏览器工具在移动模拟下的 tap 只产生 focus、不触发 click 处理器（桌面模式全部正常）。抽屉/专注开关为同一 class-toggle 机制且桌面已验证；另补了 touchend 兼容与去抖。真机行为需在真实触屏设备复核。
- **按压/回弹瞬时画面**无法截图（回弹约 0.3s 快于截图延迟）；按键记录链路在 v2 已实证，本轮未回归变化。
- **file:// 直开未实测**：浏览器工具按策略拒绝 file://；离线性以构建零外链保证。
- 半透明高质量档为 transmission 近似参数，未与真实光学材质逐参数比对；低功耗档为普通透明近似（已在 UI 说明）。
- 帧率只记录 HUD 读数，未用专业性能工具测 GPU 帧时间；不做绝对 FPS 声明。
- 审计建议的"灰模诊断图"未单独产出（配色未隐藏几何问题的风险已通过近景裁剪检查部分覆盖）。
